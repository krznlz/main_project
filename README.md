# Интерактивный бриф для «Форма следует за функцией»

Представляет собой пошаговую форму, с помощью которой потенциальный заказчик может рассказать о своём проекте, указать исходные данные и оставить контакты для дальнейшего обсуждения. Состоит из 6 шагов и двух поп-апов: один появляется при прохождении формы, а второй при нажатии на кнопку «Связаться без брифа»

## [Реализация в коде](https://krznlz.github.io/main_project/brief.html)

Неиросеть ChatGPT использовалась, чтобы разобраться в реализации интерактивного компонента и применить изученные на занятиях инструменты к собственному проекту, особенно при написании кода для текстовых форм и для обязательного заполнения, создания анимаций
